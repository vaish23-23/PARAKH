About the model (for judges)

Model. Character n-gram TF-IDF + logistic regression, trained on 3,665 messages (15 families, English / Hindi / Hinglish). Final score = 90% model + 10% rule engine. The same weights run in your browser; nothing is sent anywhere.

Tested on families it never saw (leave-one-family-out): accuracy 93.7%, scam recall 99.9%, precision 89.9%, AUC 0.988 (rules alone: 76.8% accuracy, AUC 0.848). Alert threshold 0.45.

Hand-written unseen set (31 messages): at the 0.45 alert level, recall 100%, precision 83%. Small set, so treat as a sanity check, not proof.

Limits. The training data is template-generated, not real forwarded messages. Random-split scores of 100% are not meaningful. Before real use it needs real, consented examples, and a human-reviewed update loop.
